# 여백 — 남은 삶 시각화 (모바일웹 MVP)

생년월일만 입력하면 인생을 한 주(週) 단위 **점 그리드**(life-in-weeks)로 그려, 지금 이 순간을 조금 더 소중히 살도록 돕는 **성찰 도구**입니다.

- **긍정 리프레임**: '죽음 카운트다운'이 아니라 "남은 삶을 소중히". 위협적 톤·죽음 어휘를 쓰지 않습니다.
- **완전 로컬 계산**: 모든 계산은 브라우저(JS) 안에서만. 서버·API 없음. 입력값은 `localStorage`에만 저장(재방문 유지).
- **정적 단일 페이지**: `index.html` + `tokens.css`(디자인 토큰). 빌드 불필요.

## 기능
- 생년월일 입력 + 기대수명 프리셋(한국 평균/남/여·일본·세계 평균) 또는 직접 입력
- "인생 약 N주 중 M주를 살았습니다 · 약 K주가 남았습니다" 헤드라인
- 보조 표기: 지나온 일수 · 년/개월
- life-in-weeks 점 그리드(한 줄=1년 52주, 위→아래 나이). 지나온 주=채운 점, 이번 주=하이라이트, 남은 주=빈 점
- 인생 진행률 %+ 진행 바
- 오늘의 성찰 카드(오늘이 인생 N주째 + 회전 명언 8개, '현재를 소중히' 톤)
- 기대치 초과 시 "보너스 시간" 긍정 처리
- 상시 안전 고지 + 위기상담 안내(자살예방상담 109 / 1393)

## 상태 커버리지
입력 전(온보딩) · 입력 후(결과) · 잘못된 날짜(2월 30일 등) · 미래 날짜 · 130세 초과 · 기대수명 초과(보너스) · 재방문 복원.

## 안전 고지
본 화면은 **공개 통계 평균에 기반한 성찰용 추정치**이며 의료적 예측·진단·치료 목적이 아닙니다. 실제 삶의 길이는 누구도 알 수 없고 오늘의 선택으로 얼마든지 달라집니다. 힘든 마음이 드신다면 자살예방상담 **☎ 109 / 1393**(24시간).
